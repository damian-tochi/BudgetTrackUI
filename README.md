## Overview

BudgetTrackUI explores modern approaches to personal finance interfaces on Android, combining minimal design, structured data presentation, and responsive interactions.

The project focuses heavily on:

- Financial dashboard layouts
- Transaction visualization
- Smooth Compose-based UI rendering
- Reusable design components
- Clean mobile interaction patterns

---

## Features

-  Financial overview dashboard
-  Transaction history interface
-  Spending analytics visualization
-  Modern dark-themed UI
-  Smooth Compose animations
-  Reusable UI components
-  Responsive mobile layouts
